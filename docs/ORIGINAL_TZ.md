# Тестовое задание · ML / Computer Vision

## CadastreCheck — выявление несоответствий застройки данным кадастра

Цель: реализовать прототип системы, которая по открытым спутниковым снимкам находит здания, сопоставляет их с публичными кадастровыми данными (НСПД) и выдаёт список несоответствий с геопривязкой и оценкой уверенности.

Территория — **Ростовская область** (кадастровый округ `61`).

---

## Оценка

Оценивается: качество детекции/сегментации зданий, корректность работы с геоданными (СК, топология, допуски), устойчивость слоя загрузки данных к нестабильному неофициальному API, логика сопоставления и классификации несоответствий, воспроизводимость, честность выводов об ограничениях.

## Данные

Все источники открытые

### Спутниковые снимки

| Источник | Разрешение | Роль | Доступ |
|---|---|---|---|
| **ESRI World Imagery** | ~0.3–0.6 м | основной снимок для детекции зданий | XYZ-тайлы, без ключа; только исследовательское использование, обязательна атрибуция; дату съёмки уточнить через World Imagery Wayback / метаданные |
| **Sentinel-2 L2A** (Copernicus Data Space Ecosystem) | 10 м | вспомогательный: детекция изменений во времени, проверка «свежести» застройки | бесплатно, нужна регистрация; STAC / OData API |
| **Maxar Open Data Program** | ~0.3–0.5 м | опционально, для предобучения | только отдельные территории |

Альтернативно возможно применение Google Maps / Google Earth, Яндекс Карты, 2ГИС

### Кадастр — НСПД (nspd.gov.ru)

НСПД — преемник Публичной кадастровой карты Росреестра (ПКК).

**Официального публичного API нет.** Веб-карта работает через внутренние
HTTP-эндпоинты, которые можно использовать, но они не документированы и меняются.

Нужные слои:

- **Земельные участки** — кадастровый номер, категория земель, ВРИ, площадь;
- **Здания**, **Сооружения**, **Объекты незавершённого строительства** —
  кадастровый номер, назначение, площадь, этажность, контур.

Что учесть (это часть проверки, а не помеха):

- схемы объектов в НСПД меняются без предупреждения — парсинг не должен падать
  на неизвестных полях;
- API может отвечать медленно, с ошибками или таймаутами — нужны ретраи
  с экспоненциальной задержкой и ограничение частоты запросов;
- выгружать **только AOI**, никакой массовой выгрузки по региону;
- у многих ОКС **нет контура** (только привязка к участку) — это нужно обработать.

### Вспомогательная разметка и бейзлайны

- **OpenStreetMap** (здания) — Overpass API или выгрузка Geofabrik
  (`south-fed-district`); слабая разметка, полнота в сельской местности низкая.

## Функциональность

### Пайплайн

1. Загрузка снимка и кадастровых данных по `aoi.geojson` (с кэшем).
2. Сегментация/детекция зданий на снимке.
3. Векторизация масок в полигоны, упрощение, фильтр по минимальной площади
   (настраивается, по умолчанию 10 м²).
4. Совмещение с кадастром: учёт сдвига снимка относительно кадастра, допуски через буферы.
5. Классификация несоответствий.

### Типы несоответствий

| Код | Несоответствие | Правило (пример, пороги настраиваются) |
|---|---|---|
| `UNREGISTERED` | здание на снимке, нет ОКС в кадастре | нет пересечения с контуром ОКС, а на участке ОКС не зарегистрированы |
| `MISSING` | ОКС в кадастре, на снимке нет | контур ОКС не пересекается ни с одной детекцией |
| `OUT_OF_PARCEL` | здание выходит за границы участка | доля площади вне участка > 20% (с учётом буфера) |
| `NO_PARCEL` | здание на земле без кадастрового номера | не попадает ни в один участок |
| `AREA_MISMATCH` | площадь застройки ≠ кадастровой | расхождение > 10% |
| `LAND_USE` *(опц.)* | застройка на участке с неподходящим ВРИ / категорией | например, с/х назначение без права строительства |

У каждого флага — уверенность (на основе score модели и геометрии сопоставления).

## Метрики

- Сегментация: **IoU**, **F1** на уровне объектов (match по IoU ≥ 0.5).
- Несоответствия: **precision** по каждому типу на проверенной выборке.
- В `DECISIONS.md` — разбор типовых ошибок (тени, навесы, теплицы, кроны,
  сдвиг снимка) и что с ними делать дальше.

7. Отчёт или презентация на 2–3 страницы: подход, метрики, ошибки, ограничения, что делать дальше.
