# Атрибуция спутниковых снимков

## ESRI World Imagery

**Источник:** Esri World Imagery  
**Атрибуция:** Esri, Maxar, Earthstar Geographics, and the GIS User Community  
**Дата съёмки для AOI (Батайск, мкр. Койсуг):** 2022-10-07  
**Проверка даты:** ArcGIS REST Metadata API / World Imagery Wayback, проверено 2026-10-29.  
**Использование:** исследовательское/образовательное, без перераспространения.

Снимок используется в рамках тестового задания CadastreCheck. Ограничение: давность снимка (2022 г.) может влиять на достоверность флагов `UNREGISTERED` (см. `DECISIONS.md §T11`).
